# 📚 Módulo 01: Fundamentos de SQL Server

Este módulo cobre os pilares fundamentais para consultar e filtrar dados de forma eficiente no SQL Server, com foco em como o desenvolvedor lida com consultas no dia a dia.

---

## 🎯 Objetivos do Módulo
- Entender a estrutura básica de uma consulta relacional.
- Dominar o uso de filtros, ordenações e paginações.
- Compreender como funcionam os diferentes tipos de `JOINs`.
- Manipular dados textuais, datas e funções agregadas.

---

## 📋 Tópicos Abordados
1. **SELECT, WHERE e ORDER BY:** Filtrando e ordenando dados básicos.
2. **Operadores Lógicos e Condicionais:** `AND`, `OR`, `IN`, `BETWEEN`, `LIKE`, `IS NULL`.
3. **JOINs na Prática:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN` e `CROSS JOIN`.
4. **Funções de Agregação e Agrupamento:** `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`, `GROUP BY` e `HAVING`.
5. **Paginação Eficiente:** `OFFSET` e `FETCH NEXT` (evitando o velho `ROW_NUMBER()` desnecessário).
