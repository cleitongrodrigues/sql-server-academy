# 🚀 SQL Server Academy

Bem-vindo ao **SQL Server Academy**! Este repositório foi criado com o objetivo de servir como um guia prático e direto ao ponto sobre **SQL Server**, focado especialmente nas necessidades de desenvolvedores de software. 

A ideia aqui é documentar a jornada de aprendizado, transformando conceitos teóricos e dores do dia a dia de desenvolvimento em exemplos claros, scripts prontos para uso e exercícios práticos.

---

## 📂 Estrutura do Repositório

O conteúdo está dividido em módulos progressivos. Cada pasta contém explicações teóricas, scripts de exemplo, exercícios e as respectivas resoluções:

* **[01_Fundamentos](./01_Fundamentos):** Consultas básicas, filtros (`WHERE`), ordenação, funções de agregação e `JOINs`.
* **[02_Modelagem_e_DDL](./02_Modelagem_e_DDL):** Tipos de dados, criação de tabelas (`CREATE`), restrições (`Constraints`) e visões (`Views`).
* **[03_Modelagem_e_DML](./03_Modelagem_e_DML):** Manipulação de dados (`INSERT`, `UPDATE`, `DELETE`, `MERGE`) e controle de transações.
* **[04_Programacao_T_Sql](./04_Programacao_T_Sql):** Variáveis, controle de fluxo, Stored Procedures, Funções (UDFs) e Triggers.
* **[05_Performance_e_Indice](./05_Performance_e_Indice):** Anatomia de índices (`B-Trees`), índices clustered/non-clustered, planos de execução e dicas de otimização para devs.
