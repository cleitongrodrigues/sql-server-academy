# 🏗️ Módulo 02: Modelagem e DDL (Data Definition Language)

Este módulo foca na criação, alteração e estruturação de objetos de banco de dados, garantindo integridade referencial e boas práticas de modelagem relacional.

---

## 🎯 Objetivos do Módulo
- Aprender a desenhar tabelas estruturadas e normalizadas.
- Dominar os comandos de DDL (`CREATE`, `ALTER`, `DROP`).
- Garantir a integridade dos dados utilizando restrições (*Constraints*).
- Entender o impacto de tipos de dados (*Data Types*) na performance e armazenamento.

---

## 📋 Tópicos Abordados
1. **Tipos de Dados no SQL Server:** Escolha correta entre `VARCHAR`, `CHAR`, `INTEGER`, `BIGINT`, `DECIMAL`, `DATETIME`, etc.
2. **Criação de Tabelas e Constraints:** `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK`, `DEFAULT`.
3. **Alterações de Estrutura:** `ALTER TABLE` (adicionando, removendo e modificando colunas e restrições).
4. **Visões (Views):** Criação e uso de views para encapsular regras de negócio e consultas complexas.
5. **Boas Práticas de Nomenclatura:** Convenções de nomes para tabelas, colunas e chaves.
